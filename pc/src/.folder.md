# Desktop frontend

- `shell/` manages application state and the connection to native device services.
- `dashboard/` presents Agent and device state.
- `component-center/` manages built-in and installed PetUI components.
- `lib/` contains shared rendering, transport, configuration and data helpers.

Run `npm test` from `pc/` to check frontend behavior and public build configuration.

`lib/agent-bus-client.js` routes bounded, cancellable reads through the local-only `local_bridge_request` Tauri command. Dashboard injection uses the same scoped native boundary; credentials never enter the webview and no unauthenticated port fallback is used.

`lib/agent-focus.js` owns the multi-Agent model: per-Agent tagging with the real session id, merged routing rows, and a bounded device queue that always retains the selected card. Identity is `(agentId, sessionId)`; the protocol carries `sessions[].agentId`, and the top-level `agentId` is derived from the selected Session for old firmware and state/speech scope.
